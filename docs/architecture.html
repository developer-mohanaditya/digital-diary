Digital Diary - Schema + Flow (locked)

Models: small <=1000 chars - llama-3.1-8b-fp8-fast, large >1000 chars - llama-3.3-70b-fp8-fast. Daily cap 100. /push bypasses AI.

1. Database schema tree (Supabase Postgres)

public |-- categories (10 rows: DIARY-GROUP class / learning / thought / quote / work / project / life / task / inbox + ACTION deadline) | |-- id TEXT PK, label TEXT, sort_order INT | |-- captures (append-only, never update/delete rows) | |-- id UUID PK, source TEXT default telegram | |-- source_update_id BIGINT + source UNIQUE (idempotency) | |-- source_chat_id BIGINT, kind TEXT (text/voice/photo/link) | |-- raw_text TEXT, media_path TEXT | |-- command_mode (refine/verbatim/reason/think), command_category FK -> categories | |-- status (received/processing/done/failed/awaiting_category), attempts, last_error, received_at | |-- thoughts (what you read on web) | |-- id UUID PK, capture_id FK -> captures.id | |-- day DATE (local day in diary TZ), captured_at TIMESTAMPTZ | |-- category FK -> categories, category_source (tag/auto/manual) | |-- mode (refine/verbatim/reason/think) | |-- clean_text TEXT (shown), raw_text TEXT (kept forever), reasoning TEXT | |-- indexes: (day), (category, day) | |-- category_changes (audit of web moves) | |-- id UUID PK, thought_id FK -> thoughts, from_category FK, to_category FK, changed_at | |-- links (future link capture) | |-- id UUID PK, capture_id FK -> captures, url, title, description, created_at | |-- settings (key/value) | |-- key TEXT PK (timezone), value TEXT, updated_at | |-- heartbeats (cron keep-alive) |-- id BIGINT PK, beat_at, note LANE A (diary notes, same viewer): class / learn / thought / quote / work / project / life / task / inbox -> thoughts -> dashboard groups+calendar LANE B (action lane, different viewer): deadline category + reminders(kind=deadline/review) -> Telegram pings with Done + dashboard badge RLS: enabled on all tables incl. reminders, no public policies. service_role only.

2. Note flow: Telegram to dashboard

1. You send Telegram messageLANE A (grouped): /class /learn /thought /quote /work /project /life /task or plain text + modes /push /reason /think. LANE B (separate): /deadline OR deadline/due words OR review-it-later phrases. /timezone /start as before.
2. Worker webhook POST /telegram/webhookChecks X-Telegram-Secret, ignores chat != ALLOWED_CHAT_ID, /start replies help, voice/photo replies not-wired-up.
3. parseCommand + insertCapture firstRaw stored before anything else with (source, update_id) dedup. Duplicate update_id -> ignored, no double entry. /timezone handled here, no thought.
4. Route (locked dual-model)/push or tagged-verbatim: skip AI, clean=body. Else if len<=1000 chars: Workers AI 8B-fast. Else: Workers AI 70B-fast. /reason//think always AI. Any AI error/quota -> fallback Inbox/auto, original kept.
5. Workers AI refineSystem: rewrite carefully, keep all facts, return JSON clean_text + category (1 of 9). max_output = min(1500, input*1.6+200), temp 0, 8s timeout, 1 retry. Invalid -> discard, use original.
6. insertThought + mark doneday = localDay(msg.date, stored TZ), category_source tag/auto, mode kept, clean+raw saved. setCaptureStatus done. Reply Saved to X.
7. Read on web dashboardWorker serves public/ + demo/. Day/Week/Month/Year activity, calendar, hour chart, Day groups by category, Move-to (local), Raw tag shows raw_text.

3. Deadlines + Reviews (same alert path, different schedules)

reminders |-- id UUID PK, capture_id FK, thought_id FK nullable |-- kind (deadline/review), title TEXT (140ch) |-- due_at TIMESTAMPTZ (deadlines), next_remind_at TIMESTAMPTZ |-- status (pending/done/snoozed), source (explicit/heuristic/ai) |-- snooze_count INT, created_at, done_at |-- indexes: (status, next_remind_at), (thought_id)
Detect/deadline explicit OR words: deadline, due date, submit by, finish X by, in N days. Review: review it later, come back, read again, check this again/later, revisit, follow up. AI hook upgrades dates later.
ScheduleDeadline: due parsed (3rd nov, this weekend, in 3 days, tomorrow) else +3d. First ping T-3. Review: same-day 18:30 if before 15:00 else next-day 18:30, urgent pulls earlier, max +2d.
Alert via Telegram with DoneCron 06:00 + 12:30 UTC sweeps pending where next_remind_at <= now. Sends with inline Done button (done:id). Deadlines reschedule +24h until due. Reviews: 2nd ping +2d then done. Done callback marks done, no more pings.

Daily caps: 100 refines/day, 6000-char input max. 101st saves as-is to Inbox. Run migrations/0005_reminders.sql in Supabase SQL editor.
