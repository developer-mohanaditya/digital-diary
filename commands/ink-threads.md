Use the `ink` skill. Unit `threads`, depth `note`: one note per separate line of work, each with its
own outcome and its own category. All of them go in one request, so the receipt and the Telegram
message come back once.

Threads named on the command line: $ARGUMENTS

If nothing follows the command, read them from the session. Report the receipt, then stop.
